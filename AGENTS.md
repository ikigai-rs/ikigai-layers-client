# AGENTS.md

`ikigai-layers-client` is the `ikigai-layers` command: take part in an ikigai layer over QUIC
with nothing but Python.

- Read [ACCESSIBILITY.md](ACCESSIBILITY.md) before any change to output people read: messages,
  pages, terminal text.
- Run `just gates` (or `scripts/gates.sh`: ruff check, ruff format --check, pytest) before
  opening a pull request.
- Security reports go through
  [private vulnerability reporting](https://github.com/ikigai-rs/ikigai-layers-client/security/advisories/new),
  never a public issue.
- Write American spelling (behavior, color, labeled).
